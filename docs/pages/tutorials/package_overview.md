---
title: "Package"
---

Learn how to derive the cartographic outputs a web map needs from one
clean polygon layer.

- [package-polygons](package_polygons/): dissolve into every detected
  coarser admin level.
- [package-points](package_points/): one label point per admin unit per
  level.
- [package-lines](package_lines/): one deduplicated boundary-line
  network.
- [package](package/): run all three in one call.
