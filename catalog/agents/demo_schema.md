# AGENTS.md: schema demo inputs

Inputs for the topo-tools schema tools. `schema-map` writes a crosswalk from the source columns to `adm{{n}}_name`/`adm{{n}}_code`, working out the admin hierarchy from the values themselves. `schema-crosswalk` writes the same crosswalk and applies it.

- [admin2-simplified](admin2-simplified/AGENTS.md): 342 gemeenten with CBS column names, simplified to 100 m. Input for `schema-map` and `schema-crosswalk`.
